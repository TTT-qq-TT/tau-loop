# Verification Profile: reliability

Use this profile for recurring failure fixes, prevention work, and harness tightening.

## Checklist

- Reproduce the failure when practical, or state why reproduction was not feasible.
- Verify the prevention now exists in docs, checks, automation, or constraints.
- Add or update `.harness/failure-log.md` when the issue could recur.
- Check that the new prevention is easier to repeat than the original manual fix.
- Record any remaining blind spots where the failure could still slip through.
