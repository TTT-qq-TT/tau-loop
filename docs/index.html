τ-Loop · TauLoop

τ = 2π: one complete, evidence-backed turn of work — a lightweight workflow harness that keeps coding agents on track from spec to verified checkpoint.

You name the goal. The agent shapes the work, verifies it, and leaves the next step behind — in the project, not trapped in one chat.

View on GitHub Quick start

Why TauLoop

  • Minimal — one command (tau init), no daemon, no state machine, no command surface.
  • Evidence-backed — spec → execute → verify → checkpoint, with files as the source of truth.
  • Long-running tasks — the agent sleeps while the OS owns the process, then wakes to check.
  • Cross-platform — macOS, Ubuntu, and Windows (native PowerShell, CI-verified).

Works with Codex, Claude, and any coding agent that reads AGENTS.md.
