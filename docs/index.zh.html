τ-Loop · TauLoop

τ = 2π：一个完整、有证据支撑的工作轮次——一个轻量 workflow harness，让 coding agent 从 spec 一路走到验证过的 checkpoint。

你定目标。agent 拆解工作、验证结果、把下一步留在项目里——而不是困在某一段聊天里。

前往 GitHub 一分钟上手

为什么选 TauLoop

  • 极简——只有一个命令（tau init），没有 daemon、没有状态机、没有多余的命令面。
  • 证据驱动——spec → 执行 → 验证 → checkpoint，文件即真相。
  • 长任务——进程交给操作系统托管，agent 睡觉后醒来检查，不占用会话。
  • 跨平台——macOS、Ubuntu 与 Windows（原生 PowerShell，CI 全绿验证）。

适用于 Codex、Claude 以及任何读取 AGENTS.md 的 coding agent。
